# WORKORA — Where Skills Meet Opportunities

A premium freelance marketplace frontend inspired by Fiverr and Upwork, built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

---

## ✨ Features & Highlights

- **Sophisticated Minimalist Aesthetic**: Off-white/slate-950 palette with signature emerald accents (`#059669`), generous whitespace, Plus Jakarta Sans typography, and subtle multi-layered drop shadows.
- **Interactive Dual-Mode Hero**:
  - Segmented search switcher between **Find Talent** and **Browse Projects**.
  - Live query filtering and popular skill chips (Next.js, Figma, AI Agents, Brand Strategy, Technical SEO).
  - Floating high-craft visual composition showcasing verified talent, milestone escrow release, and 48-hour matching badges.
- **Trust & Statistics Section**:
  - Clean metric cards for *Talented Freelancers (48,000+)*, *Projects Completed (120,000+)*, *Happy Clients (99.4%)*, and *Time to Match (< 48 hrs)*.
  - Transparent demo content banner and partner logo strip.
- **Popular Categories (8 Core Disciplines)**:
  - Web Development, UI/UX Design, Graphic Design, Content Writing, Digital Marketing, Video Editing, Mobile App Development, and AI & Automation.
  - Clickable category cards that dynamically filter the featured talent roster.
- **Featured Freelancers Roster**:
  - High-resolution avatars with live availability indicator.
  - Transparent hourly rates, star ratings, review counts, and skill tags.
  - **Interactive Profile Modal** with case studies, quantifiable results, client quotes, and simulated project inquiry submission.
- **How Workora Works**:
  - 3-step streamlined process: *Discover Talent* → *Collaborate* → *Get Things Done*.
  - Dual perspective toggle: **For Clients** vs **For Freelancers**.
- **High-Impact CTA Banner**:
  - Distinctive deep navy background with radial emerald glows.
  - Direct action triggers for *Join as Freelancer* and *Hire Talent*.
- **Comprehensive Footer & Auth Modals**:
  - Navigation links, company/legal modals, weekly newsletter subscribe form with feedback state, and social media handles.
  - Interactive **Log In** & **Sign Up** modal with quick demo credential autofill.

## 🚀 Getting Started

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
